# RSS feeds for Dropout.TV
Personally, I am a big Dropout.tv fan, and the website has no built-in RSS support. Luckily, since RSS is so simple, I made my own, and it is available for anyone to use. You can follow any show’s RSS feed listed here. There are hourly updates and new shows are added automatically.

For maximal reproducibility, create a Conda environment using:
```bash
conda create --file environment.yaml
```
Then, activate using `conda activate dropout-rss`.

Alternatively, install using `pip install -r requirements.txt` with `Python 3.13.14`.
